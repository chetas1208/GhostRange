# GhostRange visual language (M20 locked)

## Chamber

Near-black void (`--gr-void`), sparse grid, depth fog (18–55), cold graphite surfaces. Negative space is intentional.

## Semantic color

| Role | Token / hue |
|------|-------------|
| Normal topology | cold white, `--gr-cyan` accents |
| Active compute | electric cyan |
| Causal / experimental | restrained violet `--gr-violet` |
| Warning / uncertainty | amber `--gr-amber` |
| Attack / refuted | red-orange `--gr-failure` |
| Verified | restrained green `--gr-mint` |
| Simulated | HUD `◇ SIMULATED` + fixture-driven markers |

## Bloom

Selective only (`GhostCanvas` BloomGate): selection, active attack, worker provisioning, world verifying. Never full-scene glow.

## Typography

`--gr-font-sans` for HUD; `--gr-font-mono` for inspector numerics. Small caps labels; sentence case for explanations.

## DOM vs 3D

3D: topology, worlds, DAG, workers, evidence constellation. DOM: HUD, inspector, timeline, command surface, reports.
