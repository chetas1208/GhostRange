# GhostMesh UI (3 primary tabs only)

## Multiverse

- `MeshSignal` — single abstract contribution (wireframe octahedron)
- `KnowledgeCluster` — aggregated LOD
- `ApplicabilityBridge` — to local twin when possibly applicable
- `FederationAnchor` — membership ring, not remote infra

**Never** render another tenant's topology.

## Execution

- `MeshPriorFlow` + `MeshExecutionHint` DOM — remote prior ≠ Scheduler

## Evidence

- `MeshPanel` — validation, quarantine, privacy label SIMULATED_MESH
- `ContributionQuarantine`, `RevocationBreak`, `LocalValidationFork`

Coalesce high-volume contributions via clustering — do not instantiate 10k meshes.
