# Self-improvement boundary

Learners **cannot**:

- Modify GhostShield invariants or policy engine rules
- Self-promote without regression + human + GhostShield
- Train on quarantined/poisoned experience (eligibility gate)
- Increase hard budget or expose secrets

Learners **can** (M18 v1):

- Propose versions of approved learning surfaces
- Offline train/evaluate/shadow

Promotion is a **protected action** like worker create.
